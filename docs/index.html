Frequently asked questions

Answers to the questions reef keepers actually ask before installing.

Is Reef Monitor really free?
Yes. 100% free, no in-app purchases, no subscription, no premium tier, no ads. There is nothing locked behind a paywall. The author runs no server (the app is entirely offline) and the operating cost is zero.
Does Reef Monitor work offline?
Yes. The app makes zero network requests. All readings, dosing entries, and water-change records are stored locally in SQLite on your device. You can use the app in airplane mode.
Does Reef Monitor have Salifert test kit timers?
Yes. The nitrate test has a 30-second shake timer plus a 3-minute wait timer. The phosphate test has a 30-second shake timer. Both run inside the log entry screen with progress bars and haptic feedback on completion.
Can I track multiple tanks?
Yes. Reef Monitor supports unlimited tanks. Each tank has its own readings, alert thresholds, dosing log, and water-change log. Switch tanks in one tap from any screen.
Which parameters can I log?
Up to 15: temperature, salinity, pH, alkalinity, calcium, magnesium, potassium, strontium, iodine, boron, nitrate, phosphate, ammonia, nitrite, and silicate. You can enable only the ones you actually test and hide the rest.
How do I export my data?
Open Settings and tap Export CSV. The file is shared through the standard iOS share sheet. You can save it to Files, email it, or open it in any spreadsheet app. The format is importable back into Reef Monitor.
Which languages does Reef Monitor support?
15: English, French, German, Spanish, Portuguese, Italian, Dutch, Russian, Japanese, Korean, Chinese, Arabic, Hindi, Turkish, and Polish. The app auto-detects your device language; no setup needed.
Is Reef Monitor available on Android?
Not yet. The codebase is cross-platform (React Native via Expo), and an Android release is on the roadmap. iPhone is the current focus.
How is this different from Aquarimate or Reef Buddy?
Reef Monitor is the only app in the category with built-in Salifert kit timers. It is 100% free with no premium tier, while Aquarimate is $9.99 paid and Reef Buddy uses a freemium with subscriptions. Reef Monitor also runs fully offline with no cloud sync, no account, and no analytics. See the comparison table above for the full breakdown.
